# Japan Econometrics Model

## 📌 Visão Geral
Modelo econométrico BVAR estrutural e RegARIMA para análise da economia do Japão.

## ⚙️ Estrutura do Projeto (`src/`)
- `1- data_collection/`: Recolha automatizada de dados.
- `2- data_cleaning/`: Limpeza e tratamento das séries.
- `3- feature_engineering/`: Transformação de variáveis e ajuste da taxa-sombra.
- `4- plot data/`: Gráficos descritivos.
- `5- models/`: Estimação dos modelos BVAR e ARIMAX.
- `6- evaluation/`: Métricas, validação cruzada, IRF e FEVD.
- `7- forecast/`: Projeções e simulação dos 4 cenários macroeconómicos.
